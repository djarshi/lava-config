# Stealth units

Some people dont like their bases exploded....   
Here is some training wheels. 

## Allow stealth
Yes we like exploding nooby bases who don't have defenses against stealth. 
```
!tide repeat
```

## Commando Pack
Add the Armada Vandal and Legion Saboteur. Commandos are easier to reveal, leave corpses when they die.
```
@tweakdefs ${COMMANDO_PACK}
```

## Some Stealth Off
No epic commando's

```effect
@tweakdefs ${EPIC_COMMANDO_OFF}
```
